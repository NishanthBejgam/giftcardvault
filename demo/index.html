Your cards live in this app’s private storage,
          encrypted with your master password. Uninstalling the app deletes

Auto-lock

        
When to lock the vault after you switch to another
          app. Copying a voucher code usually means a trip to a shopping app and
          back, so this is not set to lock instantly.

        

        
Whatever you choose, your codes are never shown in
          the recent-apps preview, and the vault always locks when the app is
          closed.

      


      
      

        
Text size

        
Starts on your phone's own font size. Pick another just for Gift Card Vault.

        

          
          
          
          
        

      


      

        
Fingerprint unlock

        
Opens the vault with your fingerprint instead of
          typing the master password. Your password is kept in this phone’s
          secure store and released only on a match.

        
This is a convenience, not a second lock — the
          vault file itself is protected by your master password exactly as
          before, and you can always type it instead. Because you will rarely
          type it, it is worth making it a long one.

        
        
        
        
        
On: opening the app asks for your fingerprint straight away, so the vault opens without tapping anything. Off: the lock screen waits until you tap the fingerprint button. After you press Lock yourself, it always waits.

Change the password that encrypts your cards. You need the current one.

Export

        
Saves an encrypted copy you can share to Drive, mail
          or a cable. It is the same file format the Windows and Mac apps use,
          so it opens there too — with this same master password.

        
        
        
Export comes with Yearly or Lifetime. Importing a backup works on every plan.

      


      
      

        
Changing phones?

        
Your gift cards do not move by themselves. Four steps:

        
    
          
  1. Export above (Yearly or Lifetime) and send the file somewhere you can reach from the new phone: Drive, email, or a chat to yourself.
    2. 
          
  2. Install Gift Card Vault on the new phone with the same Google account. Your plan follows that account: tap Restore if it does not show.
    3. 
          
  3. Create a vault there. Using the same master password keeps things simple.
    4. 
          
  4. Import the file below on the new phone, with the password it was exported with. Then turn fingerprint unlock on again.
    5. 
        

      


      

        
Import

        
Open a GiftCardVault_<date>.dat backup made with Export, on this
          phone or another one. A vault.dat from the PC or Mac app opens too.

        
        
        

        
      


      
      

        
Checkout mode

        
For paying in a shop. When you open a gift card, it also shows the code as a barcode
          or QR code and turns the screen to full brightness, so the cashier can scan it from your phone.

        
        
Not every shop's scanner accepts a code shown this way. If it does not scan, read the code out or let the cashier type it. Brightness goes back to normal when you close the card.

      


      
      

        
Delete stores

        
Delete every card of one or more stores at once - archived ones too. It counts down
          from 5 and asks for your fingerprint or master password, and you can undo it for 10 seconds.

    How your gift cards are protected
    
      
      
        
    • Nothing central to hack. There is no account, no server and no cloud copy of your vault.
      • 
        
    • Strong encryption. Your gift cards are kept in one AES-encrypted file with a tamper check, locked with a key made from your master password.
      • 
        
    • Fingerprint unlock lives in the secure chip. If you turn it on, your master password is kept in the phone’s secure hardware and released only on a fingerprint match.
      • 
        
    • No internet access. The internet permission is removed from the app, so Android itself blocks any network connection. Subscriptions go through the Play Store app.
      • 
        
    • It never leaves on its own. Android cloud backup and phone-to-phone transfer are turned off for this app, and debugging is off.
      • 
        
    • Hidden from view. Screenshots, screen recording, screen sharing and the recent-apps preview are blocked. Apps that misuse accessibility cannot read the vault, and other apps cannot draw over it while it is open.
      • 
        
    • Only Gift Card Vault’s own code runs. Text you share in, a screenshot or a file you import can add gift cards, never run anything.
      • 
        
    • The small things too. Codes are masked until you tap and hide again after 45 seconds, copied codes clear from the clipboard after 45 seconds, and scanning runs offline on the phone.
